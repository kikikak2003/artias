[README.md](https://github.com/user-attachments/files/34237194/README.md)# Artias Website Prototype

A responsive, interactive front-end prototype for the Artias digital art marketplace.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `artias-website`.
2. Upload `index.html` to the repository root (or upload the ZIP contents).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish. The public URL will appear in the Pages section, usually:
   `https://YOUR-USERNAME.github.io/artias-website/`

This is a front-end demo only. Login, payments, downloads, messaging, and posting use simulated interactions; no real accounts, transactions, or data storage are connected.
